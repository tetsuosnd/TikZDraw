# v0.2：専門パレットとソース編集

## 依頼と決定

ユーザーが tikz-feynhand / circuitikz 対応を依頼し、作図・編集・保存・TeX 出力・
検証・.app 更新・GitHub push の計画を承認した。
途中の追加指定で、両パレットは通常表示から外し、オプションとして個別に有効化することにした。
さらに TikZ/TeX ソースの読込・編集・図への反映も承認済み。
対象はアプリの出力と同じ構文で、任意マクロ等の逆解析は約束していない。

## 使い方

- `dist/TikZ Draw.app` が v0.2。通常作図で起動する。
- 「追加パレット…」または「表示」メニューで Feynman 図／回路図を個別に表示する。
- 「作図例を開く」で現在のパレットの例、「混在図の例」で両パッケージを使う例を開く。
- 「開く」で `.tikz` / `.tex` を読む。下部の「ソースを編集」→「図に反映」でも変更できる。
- 「保存」は `.tikzdraw`。原文の字下げやコメントは保持しない。

## 実装の正本

`core/document.mjs` が保存形式、`core/specials.mjs` が専門図形の仕様・出力、
`core/import-tex.mjs` が直接解析、`ui/specials.mjs` が SVG の概略表示。
ソースを JSON メタデータへ隠して読み戻す方式ではない。
新図形も format version 1 に追加し、従来の通常図形はそのまま読める。
表示設定はローカル保存で、図面データと分けている。

## 検証と注意

単体 24 件、実 Electron 20 件、TeX コンパイル 10 件が PASS。
必要な通常図・専門図・混在・日本語・ソース変更後の PDF を生成して見た目も確認した。
FeynHand の `draw=none` を `draw=色` で上書きすると破線等の下に実線が残るので、
`color=色` と `\feynhandlinesize` で指定する。回路の電圧方向は RP 規約を固定する。
画面は編集用の概略で、実 TeX の描画そのものではない。

読込の文法・一次資料は `docs/package-support.md`、現状は `SESSION.md`。
ユーザーの新しい図を扱う際、未対応構文を黙って落として図を変えないこと。
エラー時は図とソースを保持し、保存は元の TeX を JSON で上書きしない。
ソース編集中の破棄・終了と新規読込も、未保存データの保護対象である。

## 次の作業

ユーザーが作図とソース編集を試し、操作感や追加記号の必要性を判断する。
任意の外部 TeX の完全な編集・正確な TeX レンダリング・未選択の部品が実装済みだと扱わない。
