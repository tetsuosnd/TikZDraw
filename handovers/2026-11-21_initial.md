# TikZ Draw 初版の引き継ぎ

## ユーザーの依頼と決定

WinTpic のようなデスクトップ作図アプリを作り、TikZ のソースを出力する。
作図・編集・保存・書き出し・実 TeX 検証という計画を承認済み。
ユーザーが Electron を明示指定した。対象はまず macOS、UI と説明書は日本語。
アプリ名は仮に TikZ Draw。

## 使い始める

`dist/TikZ Draw.app` を Finder で開く。初期画面の「サンプルの図を開く」で編集を試せる。
開発実行・ビルド・検査の正本は `CLAUDE.md`、現在状態と測定値は `SESSION.md`、
判断理由は `DESIGN.md`。

## 検証済みの範囲

- `npm test` 9 件、実 Electron 操作 12 件、TeX コンパイル 4 件が PASS。
- 完成した .app の起動も検証。ローカル assets、KaTeX、preload、sandbox を確認。
- 出力 PDF は Poppler で見た目を確認した。
- 最小ウインドウ（1060×700）でもステータスが画面内に収まる。サイドバーはスクロール可能。
- 閉じる直前の未確定プロパティ入力も保存確認の対象になる。

## 次の作業

ユーザーが初版を試し、WinTpic の使い方に照らして操作感と追加機能を判断する。
未対応の機能を既に実装済みと扱わない。Windows 配布、任意 TikZ/WinTpic の取込、
署名・公証はまだ無い。KaTeX は実 TeX の完全なプレビューではない。

## 作業上の注意

`AGENTS.md` は `CLAUDE.md` への相対 symlink。
ソース正本はこのリポ。モデルの座標は左上原点の mm、TeX 出力で y を反転する。
制御点から SVG と TikZ を生成するため、片方だけを編集する描画ロジックを追加しない。
`.app` は `dist/` の生成物で Git に入れない。`npm run build:mac` で再生成する。
Electron 45 の npm パッケージは初回起動時に実行本体を取得する。
ネットワークが必要になるのは初回依存導入・実行本体取得のときで、作図時の通信は使わない。

## リモートへの保存

private リポ `tetsuosnd/TikZDraw` は作成済み、ソースはローカル commit 済み。
push は自動承認レビューが「内容と宛先への明示承認が必要」として拒否した。
ユーザーへアプリのソース一式と prefs のリポ一覧 1 行の送信確認を提示しており、
返答を受けてから push する。承認前に別経路で回避しない。
