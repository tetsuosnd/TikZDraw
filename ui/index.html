TikZ Draw の使い方

        
      

      
図形をマウスで描き、右のプロパティで仕上げます。

      

        
直線・長方形・円・楕円・曲線

        
用紙をドラッグ。円・円弧は中心から半径を指定します。

        
折れ線

        
頂点を順にクリックし、Enter またはダブルクリックで確定。

        
選択・編集

        

          クリックで選択、Shift
          で追加選択。ドラッグで移動。空白のドラッグで範囲選択。青い点を動かして形を編集します。
        

        
文字・数式

        

          用紙をクリックして配置。数式は右の欄に \frac{a}{b} のように入力します（$
          は不要）。
        

        
ショートカット

        

          V 選択 / L 直線 / A 矢印 / R 長方形 / C 円 / B 曲線 / T 文字 / M 数式
Delete 削除 /
          矢印キー 微移動 / Shift＋矢印 大きく移動
⌘D 複製 / ⌘Z 元に戻す / ⇧⌘Z やり直す / Esc
          中止
        

        
保存と書き出し

        

          左上のパレットで通常作図・Feynman
          図・回路図を切り替えます。異なるパレットの図形は同じ用紙で混在できます。粒子・部品の種類やラベルは右のプロパティで変更します。
        

        
専門図形

        

          伝播線の直線・曲線・ループを切替でき、曲線は制御点で編集します。回路部品は端点をドラッグで調整します。各ラベルは
          LaTeX 数式で指定し、$ は付けません。
        

        
パッケージ

        

          必要な tikz-feynhand / circuitikz を単体 TeX
          のプリアンブルに自動指定します。画面の専門記号は概略表示で、最終的な形状・ラベル配置は TeX
          側で確認してください。
        

        
再編集用ファイル

        

          .tikzdraw は再編集用。.tikz は本文へ読み込む図、.tex
          は単体でコンパイルする文書です。
        

      

      

        編集時の数式と実際の TeX では字形・対応コマンドに差があります。日本語を含む単体 TeX は
        LuaLaTeX でコンパイルしてください。
